# Prueba Técnica — Global Reporting Analyst

## Descripción

Repositorio correspondiente a la prueba técnica de Juan Castiblanco.

El proyecto utiliza Python para análisis y transformación de datos, SQLite para consultas SQL y Jupyter Notebook como entorno principal de desarrollo.
